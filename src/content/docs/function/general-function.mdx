General functions provide common utilities that can be reused across engineering workbooks. Verify the accepted unit spelling and the returned unit before using a result in a downstream formula.

## Unit Conversion

Function: `=ee.CONVERT()`

Syntax:

```text
=ee.CONVERT(value, from_unit, to_unit)
```

### Temperature

```text
=ee.CONVERT(100, "C", "F")
=ee.CONVERT(273.15, "K", "C")
```

Representative results: `212°F`, `0°C`

### Pressure

```text
=ee.CONVERT(1, "bar", "psi")
=ee.CONVERT(101.325, "kPa", "atm")
```

Representative results: `14.504 psi`, `1 atm`

### Length

```text
=ee.CONVERT(1, "m", "ft")
=ee.CONVERT(25.4, "mm", "inch")
```

Representative results: `3.281 ft`, `1 inch`

### Mass

```text
=ee.CONVERT(1, "kg", "lb")
=ee.CONVERT(1000, "kg", "ton")
```

Representative results: `2.205 lb`, `1 ton`

### Supported unit categories

| Category | Common unit symbols |
| --- | --- |
| Temperature | `C`, `F`, `K` |
| Pressure | `bar`, `psi`, `Pa`, `kPa`, `MPa`, `atm` |
| Length | `m`, `cm`, `mm`, `km`, `ft`, `inch`, `yard` |
| Mass | `kg`, `g`, `mg`, `lb`, `oz`, `ton` |
| Volume | `m3`, `L`, `mL`, `gal`, `ft3` |
| Energy | `J`, `kJ`, `cal`, `kcal`, `BTU`, `kWh` |

Unit names and aliases are case-sensitive when indicated by the function implementation. Detailed alias and error documentation will be added in the function-level reference phase.

## Physical Constants

Function: `=ee.CONSTANT()`

Syntax:

```text
=ee.CONSTANT(constant_name)
```

| Constant | Example | Representative result |
| --- | --- | --- |
| Universal gas constant | `=ee.CONSTANT("R")` | `8.314 J/(mol·K)` |
| Standard gravity | `=ee.CONSTANT("g")` | `9.807 m/s²` |
| Avogadro constant | `=ee.CONSTANT("Na")` | `6.022e23 mol⁻¹` |
| Boltzmann constant | `=ee.CONSTANT("k")` | `1.381e-23 J/K` |
| Planck constant | `=ee.CONSTANT("h")` | `6.626e-34 J·s` |
| Speed of light | `=ee.CONSTANT("c")` | `2.998e8 m/s` |
| Stefan–Boltzmann constant | `=ee.CONSTANT("sigma")` | `5.670e-8 W/(m²·K⁴)` |
| Pi | `=ee.CONSTANT("pi")` | `3.14159…` |
| Euler's number | `=ee.CONSTANT("e")` | `2.71828…` |

The displayed values are representative rounded values. Use the returned Excel value rather than copying a rounded value from this page.
