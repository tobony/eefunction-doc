## Steam Water - IF97 Steam Table

Function pattern: `=ee.STEAMxxx()`

Calculate steam or water properties using pressure, temperature, and other supported state variables.

**Example — specific enthalpy from pressure and temperature**

```excel
=ee.STEAMH_PT(2, 150)
```

Result: `2769.09 kJ/kg`

## Seawater Properties - MIT Model

Function pattern: `=ee.SEAWTR_xxx()`

Seawater thermophysical properties are based on the MIT seawater property model. Functions in this group generally use temperature (`°C`), salinity (`g/kg`), and absolute pressure (`bar(a)`) as inputs.

**Example — density**

```excel
=ee.SEAWTR_DENSITY(25, 35, 1.013)
```

Result: `1023.34 kg/m³`

**Example — specific heat**

```excel
=ee.SEAWTR_SPCHEAT(25, 35, 1.013)
```

Result: `3.99 kJ/(kg·K)`

**Typical input ranges**

- Temperature: `0–120°C`
- Salinity: `0–120 g/kg` (typical seawater is approximately `35 g/kg`)
- Absolute pressure: `0–12 bar(a)`

Always confirm the applicable range on the detailed function page before using a result for design approval.

## Humid Air - ASHRAE

Function pattern: `=ee.HUMIDAIR_xxx()`

**Example — density from dry-bulb temperature, relative humidity, and ambient pressure**

```excel
=ee.HUMIDAIR_RHO_TDRY_RH_P(35, 0.6, 1.013)
```

Result: `1.13082 kg/m³`

Relative humidity is entered as a ratio, so `0.6` represents `60%`.

## Compressible Gas

### GERG2008 - Gas Property

Function pattern: `=ee.GASxxx()`

**Example — density from pressure, temperature, and gas composition**

```excel
=ee.GASRHO_PT(2, 35, Methane[0.6]&Ethane[0.4])
=ee.GASRHO_PT(2, 35, B3)
```

Result: `1.70111 kg/m³`

A cell reference such as `B3` can contain a composition string created manually or with `ee.FluidString()`.

### ISO 6976 - Natural Gas Heating Value

**Example — lower heating value by mass**

```excel
=ee.GASLHVMASS(Methane[0.6]&Ethane[0.4])
```

Result: `48630.14 kJ/kg`

## Fluid Composition Helper

Function: `=ee.FluidString()`

Create a gas-composition string from fluid names, fractions, and a mole- or mass-basis option.

```excel
=ee.FluidString({Methane;Ethane;Propane}, {0.6;0.3;0.1}, "mol")
```

Result: `Methane[0.6]&Ethane[0.3]&Propane[0.1]`

Use the result directly in a gas-property function:

```excel
=ee.GASRHO_PT(2, 35, ee.FluidString({Methane;Ethane}, {0.6;0.4}))
```

Notes:

- The default ratio method is `"mol"`.
- Use `"mass"` for mass-basis fractions.
- Excel ranges can be used for fluid names and fractions.
- This helper is intended for use with GERG2008 gas functions.

## Friction Factor of pipe

Function: `=ee.FRICTIONFACTOR()`

Calculate a pipe friction factor from inside diameter, absolute roughness, and Reynolds number.

```excel
=ee.FRICTIONFACTOR(202.74, 0.046, 213850)
```

Representative inputs:

- Inside diameter: `202.74 mm`
- Absolute roughness: `0.046 mm`
- Reynolds number: `213850`

Result: `0.0171`

## Interpolation as Linear, Cubic

Function: `=ee.INTERPOLATION1D()`

**Linear interpolation**

```excel
=ee.INTERPOLATION1D(1.5, {1;2;3}, {10;20;50})
=ee.INTERPOLATION1D(1.5, B1:B3, C1:C3)
```

Representative result: `15`

**Cubic interpolation**

```excel
=ee.INTERPOLATION1D(1.5, {1;2;3}, {10;20;50}, "cubic")
=ee.INTERPOLATION1D(1.5, B1:B3, C1:C3, "cubic")
```

Representative result: `10`
