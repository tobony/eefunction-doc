## Start using eeFunction

<CardGrid>
  <Card title="1. Check compatibility" icon="approve-check">
    Review the supported Excel environments and current limitations in [Getting Started](/user-guide/getting-started/).
  </Card>
  <Card title="2. Install the add-in" icon="add-document">
    Follow the standard [Installation](/user-guide/installation/) guide. Use [Manual Installation](/user-guide/installation_local/) only when required.
  </Card>
  <Card title="3. Enter a function" icon="pencil">
    Type `=ee.` in an Excel cell, select a function, and verify the parameter order and units before calculation.
  </Card>
  <Card title="4. Review the result" icon="information">
    Confirm the calculation model, valid input range, result unit, and platform notes in the function reference.
  </Card>
</CardGrid>
